Začínáme

Instalace firmwaru

Firmware je určený pouze pro Waveshare ESP32-S3-Touch-LCD-2.1. Připravte si datový USB kabel a desktopový Chrome nebo Edge.

  1. 1
    Připojte hodiny k počítači.

    Můžete použít kterýkoliv ze dvou USB‑C konektorů. Pokud se zařízení neukáže, zkuste druhý konektor, jiný datový kabel a přímý port bez USB hubu.

  2. 2
    Otevřete instalační stránku.

    Na hlavní stránce v části Instalace zvolte stabilní verzi a klikněte na Připojit zařízení.

  3. 3
    Vyberte sériový port a spusťte instalaci.

    První čistá instalace může smazat dřívější uživatelská data. Během zápisu kabel neodpojujte.

  4. 4
    Nastavte Wi‑Fi.

    Pokud tento krok přeskočíte, hodiny po startu zobrazí QR kód pro bezpečné prvotní připojení.

Chrome nebo Edge na počítačiWeb Serial není podporovaný v Safari ani v běžném mobilním prohlížeči.

Po instalaci

První spuštění

Po připojení k síti se na displeji objeví IP adresa. V zařízení na stejné Wi‑Fi otevřete http://waveshare-hodiny.local/. Pokud se stránka neotevře, použijte zobrazenou IP adresu.

Nejrychlejší nastavení

  • Vyberte jazyk.
  • Vyhledejte město.
  • Zvolte Open‑Meteo, TMEP.cz nebo Home Assistant.
  • Nastavte vzhled, jas a stránky.
  • Klikněte na Uložit změny.

Bez Home Assistantu

Hodiny fungují samostatně s Open‑Meteo. Stačí vybrat město. TMEP.cz lze přidat později pro hodnoty z vlastních čidel.

Podrobnější volby

Nastavení přes web

Webové rozhraní je určené pro zařízení ve stejné důvěryhodné síti. Nabízí více možností než nastavení na displeji, ale změny se použijí až po stisku Uložit změny.

Co nastavíte

  • Zdroj dat, město a časové pásmo
  • Ciferník, datum, barvy a metriky
  • Počasí, předpověď a meteoradar
  • Jas, noční režim a střídání stránek
  • Webové heslo a aktualizace

Záloha nastavení

Před větší změnou si stáhněte šifrovanou zálohu. Heslo k ní si bezpečně uložte — bez něj zálohu nelze obnovit. Wi‑Fi údaje se zálohou nemění.

Nezveřejňujte přístupové údajeDo screenshotů ani issue nevkládejte Home Assistant token, TMEP.cz URL, hesla nebo URL ovládacího API.

Nové verze

OTA aktualizace

Hodiny se mohou aktualizovat přímo přes Wi‑Fi. Ve webovém nastavení lze automatické aktualizace zapnout, nebo v systémové stránce hodin spustit ruční kontrolu.

  • Běžná OTA aktualizace zachová Wi‑Fi i uloženou konfiguraci.
  • Během stahování hodiny nevypínejte a vyčkejte na restart.
  • Pokud kontrola nic nenajde, ověřte internet, správný čas a zapnutý režim aktualizací.
  • Instalace z prohlížeče je vhodná pro první instalaci nebo obnovu; úplné smazání dat používejte jen vědomě.

Když něco nejde

Nejčastější potíže

Instalátor nevidí zařízení

Použijte desktopový Chrome nebo Edge, datový kabel a vyzkoušejte oba USB‑C konektory. Odpojte USB hub a připojte hodiny přímo k počítači.

Hodiny se nepřipojí k Wi‑Fi

Podporovaná je 2,4GHz Wi‑Fi. Restartujte hodiny a použijte QR onboarding. Zkontrolujte heslo a dostupnost sítě v místě hodin.

waveshare-hodiny.local se neotevře

Telefon nebo počítač musí být ve stejné síti. Použijte IP adresu z nastavení hodin; některé sítě blokují mDNS nebo komunikaci mezi klienty.

Počasí nebo hodnoty ukazují --

Ověřte internet, vybrané město a zdroj dat. U Home Assistantu znovu otestujte URL, token a entity. U TMEP.cz ověřte exportní URL.

Meteoradar není dostupný

Radar ČHMÚ se zobrazuje pouze pro polohy v České republice. Zkontrolujte uložené město a připojení k internetu.

Aktualizace se nenabízí

Zkontrolujte Wi‑Fi, internet a synchronizovaný čas. Ruční kontrolu spusťte v systémové stránce hodin nebo ve webovém nastavení.

Getting started

Install the firmware

The firmware is only for Waveshare ESP32-S3-Touch-LCD-2.1. Prepare a data USB cable and desktop Chrome or Edge.

  1. 1
    Connect the clock.

    Either USB‑C port works. If it is not detected, try the other port, another data cable and a direct port without a hub.

  2. 2
    Open the installer.

    On the main page under Installation, select a stable version and choose Connect device.

  3. 3
    Select the serial port and install.

    A first clean installation may erase existing user data. Do not unplug the cable while writing.

  4. 4
    Configure Wi‑Fi.

    If skipped, the clock displays a QR code for secure onboarding after boot.

Desktop Chrome or EdgeWeb Serial is not supported by Safari or regular mobile browsers.

After installation

First start

Once connected, the display shows its IP address. On a device in the same Wi‑Fi, open http://waveshare-hodiny.local/. If it does not open, use the displayed IP address.

Quick setup

  • Select a language.
  • Search for your city.
  • Choose Open‑Meteo, TMEP.cz or Home Assistant.
  • Set appearance, brightness and pages.
  • Select Save changes.

Without Home Assistant

The clock works independently with Open‑Meteo. Just select a city. Add TMEP.cz later for your own sensors.

More options

Settings in the web interface

The web interface is for devices on the same trusted network. It has more options than on-device settings; changes apply after Save changes.

What you can configure

  • Data source, city and time zone
  • Clock face, date, colors and metrics
  • Weather, forecast and radar
  • Brightness, night mode and page rotation
  • Web password and updates

Configuration backup

Download an encrypted backup before larger changes. Store its password safely — recovery is impossible without it. Restoring a backup does not change Wi‑Fi credentials.

Never publish credentialsKeep Home Assistant tokens, TMEP.cz URLs, passwords and control API URLs out of screenshots and issues.

New versions

OTA updates

The clock can update directly over Wi‑Fi. Enable automatic updates in the web interface, or start a manual check from the clock's system page.

  • A normal OTA update preserves Wi‑Fi and saved configuration.
  • Do not power off during download; wait for restart.
  • If no update is found, check internet, correct time and update settings.
  • Browser installation is useful for first installation or recovery; erase user data only intentionally.

When something fails

Common problems

The installer cannot see the clock

Use desktop Chrome or Edge and a data cable. Try both USB‑C ports and connect directly without a USB hub.

The clock cannot connect to Wi‑Fi

Use a 2.4GHz network. Restart and follow QR onboarding. Check the password and signal where the clock is placed.

waveshare-hodiny.local does not open

Your device must be on the same network. Use the IP shown in settings; some networks block mDNS or client-to-client traffic.

Weather or values show --

Check internet, city and data source. Retest Home Assistant URL/token/entities or verify the TMEP.cz export URL.

Radar is unavailable

CHMI radar is only available for locations in Czechia. Check the saved city and internet access.

No update is offered

Check Wi‑Fi, internet and synchronized time. Start a manual check from the clock or web settings.
